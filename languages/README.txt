# Translations for Smart MyFatoorah Gateway
#
# Source language: English (strings in PHP)
# Runtime language: follows the WordPress site locale
#
# Files:
# - smart-myfatoorah.pot          Template of all translatable strings
# - smart-myfatoorah-ar.po/.mo    Arabic
#
# To add another language (example: French):
# 1. Copy smart-myfatoorah.pot to smart-myfatoorah-fr_FR.po
# 2. Translate msgstr entries
# 3. Compile: msgfmt -o smart-myfatoorah-fr_FR.mo smart-myfatoorah-fr_FR.po
#
# WordPress loads: languages/smart-myfatoorah-{locale}.mo
